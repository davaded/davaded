## 🚀 Featured Quests

### 🎨 [frontend-art-direction](https://github.com/davaded/frontend-art-direction)
> A Codex skill for product-grade frontend work: reference digestion, visual hierarchy, motion taste, interaction states, and real UI verification.<br/>`#codex-skill` `#frontend` `#art-direction` `#design-systems`

### 🪟 [codex-manager](https://github.com/davaded/codex-manager)
> A desktop manager for multiple OpenAI/Codex accounts with quota tracking, smart switching, tray controls, CLI switching, and local auth import.<br/>`#desktop-app` `#Tauri` `#OpenAI` `#product-tool`

### ⚓ [Anchor](https://github.com/davaded/Anchor)
> A control layer for coding agents: goal/test entrypoints, replayable state, SQLite event logs, and inspectable local artifacts.<br/>`#agent-runtime` `#automation` `#Codex` `#Claude`

### 📈 [Echarts-AI-Skill](https://github.com/davaded/Echarts-AI-Skill)
> A skill-first ECharts toolkit: natural-language or table-shaped input to chart recommendation, ECharts options, and HTML/SVG export.<br/>`#AI-tooling` `#visualization` `#TypeScript`

## 🧪 Hidden Lab

- **CiteOps**: a GEO / AI Search Visibility workspace for monitoring AI answers, auditing citation readiness, and turning gaps into action backlogs.
- **App Price Atlas**: an App Store low-price dashboard for app search, global base-price comparison, and regional in-app purchase checks.
- **YESMusic Car**: a native Android car music player built with Kotlin + Media3, connected to `api-enhanced` for search and playback resolution.
- **YESVoice**: an Android x86 car-side voice output experiment with live shout, preset audio, emergency mute, and device routing.

## 🎮 Side Projects

- [api-enhanced](https://github.com/davaded/api-enhanced) - a maintained and extended fork of the Netease Cloud Music API
- [prompt-manager](https://github.com/davaded/prompt-manager) - a Tauri prompt manager with variables, tags, search, and version history
- [SubTrack](https://github.com/davaded/SubTrack) - a small subscription / tracking utility experiment
- [ECharts-Java](https://github.com/davaded/ECharts-Java) - Java object wrappers for ECharts V5 option structures
